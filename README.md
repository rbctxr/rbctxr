## Sobre mim

Estudo Engenharia de Software e fiz o bootcamp de Python para análise de dados da Reprograma. Gosto de transformar dados abertos em análises que ajudem a entender problemas reais, e também de explorar como a IA pode automatizar tarefas e apoiar o trabalho com dados. Busco minha primeira oportunidade de estágio em **dados** ou em **IA**.

- 📊 **Análise e visualização:** Python (pandas, Matplotlib), Tableau e Power BI
- 🗄️ **Também uso:** SQL, Git e GitHub
- 🤖 **IA:** mini curso de Agentes de IA (PrograMaria) e uso diário de ferramentas de IA
- 🎯 **Objetivo:** estágio em dados ou IA (aberta a vagas remotas)

Uso ChatGPT, Gemini, NotebookLM e Claude para estudar, melhorar meu código e automatizar tarefas. Estou aprendendo a ir além do uso básico: criar agentes e automações que resolvam problemas reais, sempre revisando e entendendo o que a IA entrega.

- 🧠 **Estudando:** agentes de IA, LLMs e automação de fluxos de trabalho
- 🔧 **Colocando em prática:** projetos pequenos que combinam dados e IA (em breve aqui)
- 🤝 **Aberta a estágio em IA:** áreas como automação, agentes, análise de dados com IA e apoio a times de produto

## Projeto do bootcamp

### [Análise de Dados do Disque 100: religiões de matriz afro no Brasil (2020–2023)](https://github.com/rbctxr/on34-python-s17-s18-projeto-final)

Projeto final do bootcamp, feito em grupo: análise exploratória de denúncias do Disque 100 sobre religiões de matriz afro, com gráficos em Python e dashboard no Tableau.

- 🙋‍♀️ **Minha contribuição:** coleta, junção e limpeza dos dados (8 arquivos semestrais do Disque 100, de 2020 a 2023) com pandas.
- 🧰 **Stack:** Python · pandas · Matplotlib · Tableau · Google Colab
- 🔗 [Repositório](https://github.com/rbctxr/on34-python-s17-s18-projeto-final) · [Dashboard no Tableau](https://public.tableau.com/views/PROJETOFINAL_17287731222110/Painel1)
